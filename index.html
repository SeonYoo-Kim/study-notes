1-4. 모듈 설계: 결합도와 응집도 ★★ (순서 문제 단골)

  • 좋은 설계 = 결합도는 낮게, 응집도는 높게
  • 결합도 (약함 → 강함, 좋음 → 나쁨) 자료 < 스탬프 < 제어 < 외부 < 공통 < 내용 암기: "자스제외공내"
  • 자료: 필요한 값만 인자로 / 스탬프: 자료구조(배열, 레코드)를 통째로 / 제어: 플래그로 상대 흐름 제어 / 외부: 외부 선언 데이터 참조 / 공통: 전역 변수 공유 / 내용: 상대 내부를 직접 참조
  • 응집도 (강함 → 약함, 좋음 → 나쁨) 기능 > 순차 > 교환(통신) > 절차 > 시간 > 논리 > 우연 암기: "기순교절시논우"
  • 순차: 앞 출력이 뒤 입력 / 교환: 같은 입력이나 출력을 쓰는 기능 모음 / 절차: 순서대로 실행 / 시간: 같은 시점에 실행(초기화 등) / 논리: 비슷한 성격을 묶고 플래그로 선택 / 우연: 관계 없음
  • 팬인(fan-in, 나를 호출하는 수)은 높게, 팬아웃(내가 호출하는 수)은 낮게

  • 단계 (암기: "도부이결다조") | 정규형 | 조건 | |---|---| | 1NF | 모든 속성이 원자값 (도메인이 원자값) | | 2NF | 1NF + 부분 함수 종속 제거 (기본키 일부에만 종속된 속성 분리) | | 3NF | 2NF + 이행 함수 종속 제거 (A→B, B→C 이면 A→C 분리) | | BCNF | 모든 결정자가 후보키 | | 4NF | 다치 종속 제거 | | 5NF | 조인 종속 제거 |
  • 역정규화(반정규화): 성능을 위해 일부러 중복 허용 (테이블 병합, 컬럼 추가, 요약 테이블)
  • 부분 함수 종속은 복합키일 때만 생긴다. 기본키가 단일 속성이면 1NF는 곧 2NF

  • 엔트로피 계산: H = −Σ p log₂ p. 동전 반반이면 1, 한쪽만이면 0

4-5. 평가 ★★ (계산 문제 확실)

  • 혼동 행렬: TP, FP(거짓 양성, 1종 오류), FN(거짓 음성, 2종 오류), TN
  • 정확도 = (TP + TN) / 전체
  • 정밀도 = TP / (TP + FP) → "양성이라 한 것 중 진짜"
  • 재현율(민감도) = TP / (TP + FN) → "진짜 양성 중 맞힌 것"
  • 특이도 = TN / (TN + FP)
  • F1 = 2 × 정밀도 × 재현율 / (정밀도 + 재현율) (조화 평균)
  • ROC 곡선: x = FPR(1 − 특이도), y = TPR(재현율). AUC가 1에 가까울수록 좋음, 0.5는 무작위
  • 회귀: MSE, RMSE, MAE, R²
  • 계산 예: TP 40, FP 10, FN 20, TN 30 → 정확도 70/100 = 0.7, 정밀도 40/50 = 0.8, 재현율 40/60 ≈ 0.667, F1 = 2×0.8×0.667/1.467 ≈ 0.727
  • 불균형 데이터에서는 정확도가 착시 → 정밀도, 재현율, F1
  • 데이터 분할: 학습 / 검증(하이퍼파라미터) / 테스트 / k-겹 교차 검증

4-6. 과적합과 일반화 ★

  • 과적합: 학습 오차 낮고 검증 오차 높음 (높은 분산) / 과소적합: 둘 다 높음 (높은 편향)
  • 편향 분산 트레이드오프
  • 해결: 데이터 늘리기, 데이터 증강, 정규화(L1 라쏘: 가중치를 0으로, 특징 선택 효과 / L2 릿지: 가중치를 작게), 드롭아웃, 조기 종료, 모델 단순화, 배치 정규화, 앙상블
  • 차원의 저주: 차원이 늘면 데이터가 희소해져 성능 저하

4-7. 신경망과 딥러닝 ★

  • 퍼셉트론: 가중합 + 계단 함수. 단층은 XOR 불가(선형 분리 불가) → 다층 퍼셉트론(MLP)과 역전파로 해결
  • 활성화 함수 | 함수 | 범위 | 특징 | |---|---|---| | 시그모이드 | 0 ~ 1 | 기울기 소실, 이진 분류 출력 | | tanh | −1 ~ 1 | 0 중심, 기울기 소실 | | ReLU | 0 ~ ∞ | max(0, x), 기울기 소실 완화, 죽은 ReLU 문제 → Leaky ReLU | | 소프트맥스 | 0 ~ 1, 합 1 | 다중 분류 출력 |
  • 손실 함수: 회귀는 MSE, 분류는 교차 엔트로피
  • 경사 하강법: w ← w − η × ∂L/∂w (η = 학습률, 너무 크면 발산, 너무 작으면 느림)
  • 배치(전체) / 확률적(SGD, 1개) / 미니배치
  • 옵티마이저: 모멘텀(관성) / AdaGrad(파라미터별 학습률, 점점 작아짐) / RMSProp(AdaGrad 개선, 지수 이동 평균) / Adam(모멘텀 + RMSProp)
  • 역전파: 연쇄 법칙(chain rule)으로 출력층에서 입력층 방향으로 기울기 계산
  • 기울기 소실: 깊을수록 앞층 기울기가 0에 가까워짐 → ReLU, 배치 정규화, 잔차 연결(ResNet), 적절한 초기화(Xavier, He)
  • 에폭(전체 데이터 1회) / 배치 크기 / 이터레이션(= 데이터 수 / 배치 크기, 1에폭당)

4-8. 대표 구조 ★

  • CNN: 합성곱층(필터로 특징 추출, 가중치 공유) → 풀링층(최대, 평균, 크기 축소) → 완전 연결층
  • 출력 크기 = (N − F + 2P) / S + 1 (N 입력, F 필터, P 패딩, S 스트라이드)
  • 계산: 입력 32, 필터 5, 패딩 0, 스트라이드 1 → (32 − 5)/1 + 1 = 28 / 입력 28, 필터 3, 패딩 1, 스트라이드 1 → 28(same)
  • 파라미터 수 = (F × F × 입력 채널 + 1) × 필터 개수
  • 계보: LeNet → AlexNet → VGG → GoogLeNet(인셉션) → ResNet
  • RNN: 순차 데이터, 은닉 상태를 다음 시점에 전달, 장기 의존성 문제 → LSTM(입력, 망각, 출력 게이트 + 셀 상태), GRU(리셋, 업데이트 게이트, LSTM 간소화)
  • Transformer: RNN 없이 셀프 어텐션만. Query, Key, Value / Attention = softmax(QKᵀ / √dₖ) V / 멀티헤드 어텐션 / 위치 인코딩(순서 정보) / 병렬 처리 가능
  • BERT: 인코더, 양방향, MLM(가린 단어 맞히기) + NSP, 이해 과제
  • GPT: 디코더, 단방향 자기회귀(다음 토큰 예측), 생성 과제
  • GAN: 생성자(가짜 생성)와 판별자(진짜 판별)의 적대적 학습
  • 오토인코더: 인코더 → 잠재 공간 → 디코더, 입력 재구성. 이상 탐지, 차원 축소 / VAE는 확률적 잠재 공간
  • 전이 학습: 사전 학습 모델을 가져와 미세 조정(파인튜닝)
  • 객체 탐지: 2단계(R-CNN 계열) / 1단계(YOLO, SSD) / 평가 지표 IoU, mAP

1. NCS가 뭔가

  • 국가직무능력표준(NCS)의 직업기초능력 10개 영역 중 기관이 몇 개를 골라 출제한다. 10개: 의사소통, 수리, 문제해결, 자기개발, 자원관리, 대인관계, 정보, 기술, 조직이해, 직업윤리
  • 출제 유형 3가지 | 유형 | 성격 | 체감 | |---|---|---| | 모듈형 | NCS 학습 모듈(교재) 내용을 아는지 묻는 암기형 | 개념 이론 문제. 답이 보이면 10초, 모르면 못 푼다 | | PSAT형 | 공무원 PSAT처럼 긴 지문, 표, 조건을 주고 푸는 능력 | 시간이 절대 부족하다 | | 피듈형 | 둘을 섞은 것 | 요즘 공공기관 다수 |
  • 이번 시험은 자원관리와 조직이해가 들어 있다. 이 두 영역은 모듈형 이론 문제가 섞여 나오는 경우가 많아서 피듈형일 가능성이 크다(추정이다).

2. 시험장 운용 원칙 (제일 중요)

  1. 다 못 푸는 게 정상이다. 70초에 한 문제는 PSAT형 기준으로 빠듯하다. 목표는 전부 푸는 게 아니라 풀 수 있는 걸 전부 맞히는 것이다.
  2. 한 문제에 2분 넘기면 표시하고 넘어간다. 한 문제 붙잡고 세 문제 잃는 게 제일 큰 손해다.
  3. 쉬운 유형부터 쓸어 담는다. 순서: 모듈형 이론(조직이해, 자원관리 개념) → 의사소통 일치/불일치 → 수리 자료해석 → 문제해결 조건 추리
  4. 보기부터 읽는다. 지문을 다 읽고 보기를 보면 두 번 읽게 된다. 보기의 키워드를 먼저 잡고 지문에서 찾는다.
  5. 오답 감점이 없으면 빈칸 없이 전부 찍는다. 감점이 있으면 절반 이상 확신할 때만 마킹. 시험 안내문에서 반드시 확인.
  6. OMR 마킹 시간 5분을 따로 남긴다(OMR 방식일 경우).

3-2. 수리

  • 문제 형태: 자료 해석(표와 그래프에서 옳은 설명 고르기, 가장 많음), 응용 계산(거리, 농도, 일, 확률), 도표 작성(수치를 그래프로 옮긴 것 중 틀린 것)
  • 공식 | 항목 | 공식 | |---|---| | 증감률 | (비교값 − 기준값) / 기준값 × 100 | | %와 %p | 30%에서 36%로 오르면 6%p 증가, 증가율은 20% | | 비중 | 부분 / 전체 × 100 | | 속력 | 거리 = 속력 × 시간 (단위 통일: 분 ↔ 시간) | | 농도 | 소금 양 = 소금물 × 농도 / 100. 섞으면 소금 양끼리, 소금물 양끼리 더한다 | | 일률 | 혼자 a일 걸리면 하루 1/a. 둘이 같이 하면 1/a + 1/b | | 원가와 정가 | 정가 = 원가 × (1 + 이익률), 판매가 = 정가 × (1 − 할인율) | | 경우의 수 | 순열 nPr = n! / (n−r)!, 조합 nCr = n! / (r!(n−r)!) | | 확률 | "적어도 하나" = 1 − (하나도 없을 확률) | | 평균 | 가중평균 = Σ(값 × 인원) / 총 인원 |
  • 자료 해석 요령
  • 보기 중 계산 없이 판별되는 것부터 지운다("매년 증가"는 한 해만 감소해도 틀림)
  • 정확한 계산 대신 어림산: 비교만 하면 되면 앞 두 자리로 나눈다
  • "비율"과 "수"를 헷갈리게 하는 보기가 단골이다. 비율이 올라도 실제 수는 줄 수 있다
  • 단위(천 명, 억 원, %) 확인

3-3. 문제해결

  • 문제 형태: 명제 추리, 참/거짓 말하는 사람 찾기, 자리/순서 배치, 조건 맞는 선택지 고르기(규정과 표 적용), 모듈형 이론
  • 명제
  • p → q 가 참이면 대우 ¬q → ¬p도 참. 역(q → p), 이(¬p → ¬q)는 알 수 없음
  • 삼단논법: p → q, q → r 이면 p → r
  • "어떤 A는 B이다"는 전부가 아니다
  • 참/거짓 문제: 서로 모순되는 두 진술을 먼저 찾는다. 둘 중 하나만 참이므로 경우를 두 개로 나눠 검증한다
  • 배치 문제: 확정 조건(○는 3번 자리)부터 표에 넣고, 나머지를 경우의 수로 분기한다. 표를 그리는 게 제일 빠르다
  • 규정 적용 문제(PSAT형 핵심): 선택지를 규정에 하나씩 대입해 탈락 조건부터 걸러낸다
  • 모듈형 암기 포인트
  • 문제 유형: 발생형(이미 일어난 문제, 원상 복귀) / 탐색형(더 잘하기 위한, 개선) / 설정형(미래 목표를 새로 세움)
  • 문제 해결 절차: 문제 인식 → 문제 도출 → 원인 분석 → 해결안 개발 → 실행 및 평가
  • 사고력: 창의적(자유 연상은 브레인스토밍, 강제 연상은 체크리스트, 비교 발상은 NM법과 시네틱스), 논리적(피라미드 구조, So What 기법), 비판적
  • 브레인스토밍 4원칙: 비판 금지, 자유분방, 질보다 양, 결합과 개선
  • 분석 도구: SWOT(강점, 약점, 기회, 위협 / SO, ST, WO, WT 전략), 3C(자사, 경쟁사, 고객), 로직 트리, MECE(중복 없이 누락 없이)
  • 퍼실리테이션: 제3자가 촉진, 구성원이 스스로 해결

3-4. 자원관리

  • 문제 형태: 비용 최소 선택(업체, 교통편, 숙소), 일정 짜기(회의 가능 시간), 인력 배치(조건 맞는 사람), 물품 관리, 모듈형 이론
  • 요령: 조건표를 만들고 선택지를 대입한다. 시차, 요일, 할인 조건, 최소 인원 같은 함정 조건을 먼저 표시한다
  • 해외 출장 시차 계산: 도착 현지 시각 = 출발 시각 + 비행 시간 + (현지 시각 − 한국 시각)
  • 모듈형 암기 포인트
  • 자원 4종: 시간, 예산, 물적, 인적
  • 자원 관리 과정: 필요 자원 확인 → 이용 가능 자원 수집 → 활용 계획 → 계획대로 수행
  • 낭비 요인: 비계획적 행동, 편리성 추구, 자원에 대한 인식 부재, 노하우 부족
  • 시간 관리 매트릭스(코비): 1사분면 긴급+중요(위기) / 2사분면 중요+비긴급(계획, 가장 투자해야 할 영역) / 3사분면 긴급+비중요(잡무, 전화) / 4사분면 둘 다 아님
  • 예산: 직접비(재료비, 원료와 장비, 인건비, 출장비, 시설비) / 간접비(보험료, 건물 관리비, 광고비, 통신비, 사무 비품비, 공과금) → 출장비와 인건비가 직접비라는 게 함정
  • 물적 자원 관리: 사용 물품과 보관 물품 구분 → 동일 및 유사 물품 분류 → 물품 특성에 맞는 보관 장소
  • 인적 자원 배치 원칙: 적재적소, 능력주의, 균형주의 / 배치 유형: 양적 배치, 질적 배치, 적성 배치
  • 인맥 관리: 핵심 인맥과 파생 인맥

3-5. 조직이해

  • 문제 형태: 조직도 해석(결재 라인, 담당 부서 찾기), 업무 분장, 모듈형 이론(가장 많이 나오는 영역), 국제 매너
  • 요령: 조직도 문제는 "누가 결재하나", "어느 팀 업무인가"를 조직도와 업무 분장표에서 찾기만 하면 된다. 이론 문제는 아래 암기로 끝낸다
  • 모듈형 암기 포인트
  • 조직 분류: 공식/비공식, 영리/비영리, 대규모/소규모
  • 경영 4요소: 경영 목적, 인적 자원, 자금, 경영 전략
  • 조직 구조: 기계적(엄격한 규칙, 위계, 안정적 환경) / 유기적(권한 위임, 유연, 급변하는 환경)
  • 조직 형태: 기능별(안정적 환경, 효율) / 사업별(제품, 지역, 고객별, 급변 환경) / 매트릭스(기능 + 프로젝트, 이중 보고)
  • 조직 구조 결정 요인: 전략, 규모, 기술, 환경
  • 민츠버그 경영자 역할: 대인적(대표자, 리더, 연락자) / 정보적(모니터, 전파자, 대변인) / 의사결정적(기업가, 분쟁 조정자, 자원 배분자, 협상가)
  • 포터 본원적 경쟁 전략: 원가 우위, 차별화, 집중화
  • 맥킨지 7S: 공유 가치(Shared value), 전략, 구조, 시스템, 스타일, 구성원(Staff), 기술(Skill)
  • 의사결정: 브레인스토밍, 델파이(전문가 서면 반복, 익명), 명목 집단법 / 집단 의사결정 장점(다양한 시각, 수용성) 단점(시간, 특정인 주도)
  • 조직 문화 기능: 일체감, 몰입, 안정성, 행동 지침
  • 경영 참가: 경영 참가(노사협의회), 이윤 참가(성과 배분), 자본 참가(우리사주)
  • 업무 수행 시트: 간트 차트(단계별 시간), 워크 플로 시트(흐름, 도형으로 구분), 체크리스트(수행 수준 자가 점검)
  • 국제 매너: 명함은 오른손으로, 받으면 바로 넣지 않는다 / 악수는 오른손, 윗사람이 먼저 청한다 / 이름이나 직함을 우리식으로 줄이지 않는다
  • 조직이해 문제에 기관 조직도가 지문으로 나올 수 있다. 공제회 홈페이지 조직도를 한 번 봐둔다
